# Linux Hardening Checklist

## SSH
- [ ] Отключить root-логин (`PermitRootLogin no`)
- [ ] Только аутентификация по ключам (`PasswordAuthentication no`)
- [ ] Сменить порт по умолчанию (опционально)

## Сеть/файрвол
- [ ] Политика по умолчанию DROP на input
- [ ] Открыты только нужные порты

## Обновления
- [ ] Включены автоматические security-обновления

## Аудит/логи
- [ ] auditd включён
- [ ] Централизованный сбор логов
